Button — the primary action control; use for any click action, with `variant` setting hierarchy.

```jsx
<Button>免费开始</Button>
<Button variant="outline" size="sm">Edit</Button>
<Button variant="destructive">Delete</Button>
<Button variant="ghost" size="icon">★</Button>
```

Variants: `default` (ink fill), `secondary` (warm fill), `outline`, `ghost`, `destructive` (red), `link`. Sizes: `sm`, `default`, `lg`, `icon`, `icon-sm`. Hover darkens the fill; press settles 1px.
