# 0008 · 密码安全审计仪表盘

- **优先级**:🟢 中低(功能)
- **类型**:功能
- **状态**:⬜ 未开始
- **预估工作量**:M(1.5 天)

## 背景与问题
桌面端 i18n 已有「强密码统计 / 仪表盘」概念(`home.totalPasswords` / `home.strongPasswords` 等),但移动端没有任何安全总览。可借此**复活未被使用的 home 仪表盘文案**,给用户一个「保险箱健康度」入口。

数据已具备:`updated_at` / `created_at` 可判断「久未更新」;明文可在内存中比较以判断「弱 / 重复」。

## 任务详情
- [ ] 新增「安全总览 / 健康度」页面或卡片,统计:
  - **弱密码**:长度不足 / 字符多样性低(复用 0001 的强度评估逻辑,抽成共享函数)。
  - **重复使用**:同一明文密码被多个条目使用。
  - **过期 / 久未更新**:`updated_at` 超过阈值(如 1 年)。
  - 总数、收藏数等基础统计。
- [ ] 每类给出问题清单,点击可跳转到对应条目处理。
- [ ] 计算在本地完成,不联网(与隐私定位一致);注意只在已解锁状态、避免长时间持有明文。
- [ ] 文案接入 i18n(配合 [0006](./0006-i18n-completion.md),复用 `home.*` key)。

## 验收 / 测试标准
- [ ] 构造测试数据:含弱密码、重复密码、过期密码 → 各分类计数正确。
- [ ] 点击问题项能定位到对应密码。
- [ ] 大量数据(数百条)下计算无明显卡顿(必要时后台/分帧计算)。
